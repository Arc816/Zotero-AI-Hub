# Zotero AI Hub

详细使用说明与功能逻辑请参阅：[docs/Zotero-AI-Hub-使用与功能逻辑.md](docs/Zotero-AI-Hub-使用与功能逻辑.md)。

## 1.4.5 连续问答即时刷新修复

- 同一文献因创建子笔记触发 Zotero 条目通知时，不再重建整个 AI Hub 窗格，保留实时输出绑定和滚动位置。
- 最新一轮回答始终显示在会话顶部，开始生成和完成时自动定位到新卡片。
- 每张问答卡直接显示本轮问题，方便连续追问时区分不同结果。

## 1.4.4 问答笔记与完整显示修复

- 右侧窗格中的 AI 问答完成后自动保存为当前文献的 Zotero 子笔记，并在结果卡显示“已保存”。
- 保存目标为 PDF 附件、批注或笔记时，自动向上解析到所属文献，避免把附件直接作为笔记父条目。
- 长回答提供字符数、独立滚动区与“展开全文/收起”，生成时自动跟随最新内容。
- AI 会话历史改为写入当前 Zotero 数据目录，重启后仍可恢复完整输出及笔记保存状态。

## 1.4.3 Zotero 8 点击无响应修复

- 移除 Zotero 8 插件沙箱中不可用的浏览器全局 `AbortController`，改用插件内置取消控制器。
- 取消信号仅在插件内部协调状态与显式 XHR 中断，不再作为未知选项传给 `Zotero.HTTP.request`。
- 快速分析、提问、快捷键和重试入口增加统一异常兜底；请求启动失败会直接显示原因并恢复按钮。

## 1.4.2 问答响应与停止修复

- 流式 SSE 兼容 LF/CRLF 分隔，避免部分厂商的首批输出被缓冲到请求结束才显示。
- 点击“停止”会显式中断底层 XHR，并立即恢复“发送”按钮；旧请求的迟到回调不会覆盖新请求状态。
- RAG 检索纳入同一个取消链路，检索阶段也可停止。
- 问答自动精简超长全文和历史会话，降低首字延迟与上下文费用。

## 1.4.1 阅读器首屏优化

- 将“快速分析”提升到 AI Hub 内容窗格首屏，并以独立卡片展示摘要、解释、批判分析、智能批注、翻译和关键词操作。
- 将分析上下文输入框从 7 行压缩为 4 行，避免常用操作被挤到可视区域之外。
- 移除阅读器左上角额外注入的蓝色“AI Hub”按钮，保留 Zotero 原生右侧可折叠内容窗格入口。

## 1.4.0 研究工作流增强

- 右侧 AI 工作台按文献保存独立会话，支持单条删除、复制、保存笔记、重试与停止生成。
- 修复跨文献误用最近选中文本的问题；厂商和模型选择会准确传入每次请求。
- 自动遍历父条目的 PDF/HTML 附件并读取 Zotero 全文索引，上下文带附件、页码或片段来源。
- RAG 改为来源感知的分块与增量索引，回答上下文保留可追踪的 source 标记。
- 已有 PDF 高亮可将 AI 评论写入批注；临时选区安全保存为带来源的 Zotero 子笔记。
- 在线模型列表优先于内置兜底，同厂商可随时切换不同模型，故障转移不再复用错误的模型名。
- 默认不再为每次操作自动创建笔记，可在设置中重新开启。

Zotero AI Hub 是面向 Zotero 7/8/9/10 的多厂商 AI 助手，整合文献摘要、批注、问答、翻译、思维导图、文献综述、RAG 检索和本地 MCP 服务。

## 1.3.7 Zotero 8 原生区段标题修复

- 修正区段 Fluent 文案：标题改用 `.label`，侧栏图标改用 `.tooltiptext`，防止本地化引擎清空原生折叠区段的箭头和正文。
- 使用新的原生区段 ID 重建已被旧文案破坏的阅读器节点。
- 保留 1.3.6 的 `bodyXHTML`、`XULElementBase` 自定义面板和每窗口注册架构。

## 1.3.6 原生自定义面板重构

- 仿照 Translate for Zotero，使用 `bodyXHTML` 挂载 `XULElementBase` 自定义面板，并在每个 Zotero 主窗口注册。
- 修正 `onItemChange` 的刷新返回值，确保切换条目或阅读器标签后执行面板正文渲染。
- 面板高度使用 Zotero 详情窗格的 `--details-height`，可随右侧内容窗格开合和滚动。
- 新增区段设置按钮，同时继续支持厂商切换、同厂商模型切换和在线刷新模型。

## 1.3.5 XUL/XHTML 渲染修复

- 修复错误控制台中的 `Flattening unsafe node`：右侧工作区不再把 HTML 字符串直接写入 Zotero 的 XUL 文档。
- 所有厂商/模型选择框、文本区、功能按钮和输出块现在通过 XHTML 命名空间安全导入。
- 修复因节点被压平而只剩“Zotero AI Hub”文字、没有正文及交互控件的问题。

## 1.3.4 Zotero 8 阅读器区段兼容修复

- 直接修复 Zotero 原生 `collapsible-section`，不再依赖尚未初始化完成的外层代理属性。
- 使用新的区段 ID 重建阅读器节点，清除 1.3.1 遗留的不可折叠状态。
- 增加启动诊断日志，便于区分注册失败、生命周期异常和旧节点缓存。

## 1.3.2 原生可折叠 AI 区段

- 修复右侧只显示“Zotero AI Hub”标题、没有展开箭头和功能正文的问题。
- AI Hub 现在使用 Zotero 原生可折叠区段，开合方式、箭头和状态记忆与“信息”“摘要”“附件”等区段一致。
- 折叠时显示当前“厂商 · 模型”，切换厂商或同一厂商的不同模型后即时更新。
- 从阅读器选中文本、右键菜单或工具栏进入时，会自动展开并定位 AI Hub 区段。

## 1.3.1 右侧工作台显示与体验优化

- 修复右侧只出现图标或区段标题、正文不自动展开的问题；AI 区段在右侧内容窗格内保持展开，整个窗格仍可开合。
- 新增当前文献标题、厂商配置状态、上下文字符计数、载入文献、恢复最近选文与复制最新结果。
- 快速分析扩展为摘要、解释、批判分析、智能批注、翻译、关键词，并加入核心贡献、方法评价、局限与展望快捷提问。
- 优化窄侧栏布局、空配置引导、运行中禁用、成功/失败状态和空输出提示。

## 1.3.0 右侧 AI 工作区与模型升级

- Zotero AI Hub 已迁移到 Zotero 原生右侧开/合内容窗格，文库和 PDF/EPUB 阅读器均可使用。
- 右侧窗格内可直接切换 AI 厂商，也可在同一厂商下切换不同模型；选择会立即持久化。
- 新增“刷新模型”，支持从厂商 API 在线获取模型列表；设置页每个厂商行也可独立刷新。
- 内置模型更新到 2026-08-13 的官方可用型号，并自动迁移本插件旧版本预置的过期模型 ID。
- 阅读器选中文本后的浮层、原生右键菜单和工具栏按钮都会打开并定位右侧 AI Hub 区段。

- 添加厂商时会保留其它行中尚未保存的输入，不再清空已填写内容。

## 安装与配置

1. 在 Zotero 中打开“工具 → 插件”，拖入 `zotero-ai-hub.xpi`。
2. 重启 Zotero；如果已安装旧版本，确认插件页显示版本 1.4.2。
3. 打开“Zotero AI Hub 设置”，选择厂商类型并添加。
4. 填写 Base URL、API Key 和模型；Ollama 的 API Key 可留空。
5. 点击“测试”，通过后设为默认并点击“保存设置”。
6. 在文献条目上点击右键，通过“Zotero AI Hub”子菜单使用摘要、批注、问答等功能。
7. 阅读 PDF/EPUB 时选中文本，在选择弹层点 AI 功能；也可点阅读器工具栏“AI Hub”打开右侧内容窗格。

## 开发

- `npm run typecheck`：TypeScript 静态检查。
- `npm run build`：生成 `addon/content/scripts/aiHub.js`。
- `npm run xpi`：构建并生成安装包 `zotero-ai-hub.xpi`。

源码结构：

- `src/modules/providers`：多厂商 API 适配器与故障转移。
- `src/modules/features`：摘要、批注、问答、翻译、综述、思维导图与 RAG。
- `src/modules/views`：Zotero 菜单、工具栏、设置页、聊天与输出面板。
- `src/modules/mcp`：内嵌 MCP JSON-RPC 服务。
- `addon/content`：随 XPI 打包的界面和构建产物。
