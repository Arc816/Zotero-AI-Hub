AI 厂商（Providers）ⓘ

支持 OpenAI / Anthropic / Gemini / DeepSeek / 通义千问 / 文心一言 / Kimi / Ollama 本地 / OpenRouter / 自定义兼容端点。可设优先级与故障转移。
切换厂商类型：修改表格中该行「类型」下拉框后，Base URL 与默认模型会自动填充（若原值为空）；填写 API Key 后点「测试」确认连通。

本地 Ollama 用法：① 类型选 Ollama；② Base URL 填 http://localhost:11434（默认已填）；③ API Key 可留空；④ 默认模型填 Ollama 中的模型名（如 llama3，需先在终端执行 ollama pull llama3 下载）；⑤ 确保 Ollama 正在运行且允许本机访问（部分系统需在 Ollama 设置中开启 LAN/CORS）。
