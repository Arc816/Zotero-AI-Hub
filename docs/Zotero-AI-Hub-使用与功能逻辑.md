# Zotero AI Hub 1.4.2 使用与功能逻辑手册

> 适用版本：Zotero AI Hub 1.4.2  
> 适用环境：Zotero 7–10  
> 安装包：项目根目录 `zotero-ai-hub.xpi`

## 1. 插件定位

Zotero AI Hub 是运行在 Zotero 内部的多厂商 AI 研究助手。它将 Zotero 文献条目、摘要、PDF/HTML 全文索引、Zotero 笔记和 PDF 批注整理成带来源标记的上下文，再交给所选的大模型处理。

主要能力包括：

- 在 Zotero 原生右侧可折叠内容窗格内进行摘要、解释、批判分析、智能批注、翻译、关键词提取与文献问答。
- 在 PDF/EPUB 阅读器选中文本后，直接调用 AI 摘要、批注、翻译或问答。
- 对一篇或多篇文献生成摘要、文献综述、思维导图和 Word 文档。
- 同时配置多个 AI 厂商，并在同一厂商内切换不同模型。
- 在厂商失败时按配置自动切换到其他已启用厂商。
- 可选使用 RAG 语义索引，跨当前文献、当前选择或整个已索引文献集问答。
- 启动本地 MCP 服务，使外部 AI 客户端能够查询 Zotero 并调用 AI 工具。

## 2. 整体工作流程

一次 AI 操作的逻辑如下：

1. **确定文献对象**：使用当前右侧窗格对应的文献，或文献库中当前选中的条目。
2. **取得上下文**：来源可以是阅读器选文、手工粘贴文本、“载入文献”结果，或 RAG 检索片段。
3. **确定任务**：摘要、解释、批注、翻译、关键词、问答、综述或思维导图。
4. **确定厂商与模型**：优先使用右侧窗格中明确选择的厂商和模型；其他入口使用该任务上次记住的模型，未记录时使用默认厂商及其默认模型。
5. **组装提示词**：读取设置中的相应提示词模板，用 `{{text}}`、`{{context}}`、`{{target}}` 等变量替换实际内容。
6. **调用模型**：以流式方式接收结果；如果开启故障转移且调用失败，则尝试其他已启用厂商。
7. **展示和保存**：结果实时显示在右侧“当前文献会话”中。可复制、保存为 Zotero 子笔记、重试或删除。

重要规则：如果从 A 厂商切换到 B 厂商进行故障转移，B 厂商使用自己的默认模型，不会错误复用 A 厂商的模型 ID。

## 3. 安装与升级

1. 在 Zotero 中打开“工具 → 插件”。
2. 将项目根目录中的 `zotero-ai-hub.xpi` 拖入插件管理器并确认安装。
3. 完全退出并重新启动 Zotero。
4. 在插件管理器确认版本为 `1.4.2`。

升级后如果仍看到旧界面，应先确认插件版本，再完全关闭 Zotero 后重新打开。1.4.2 不再使用阅读器左上角额外注入的蓝色“AI Hub”按钮；主要工作区位于 Zotero 原生右侧内容窗格。

## 4. 首次配置 AI 厂商

### 4.1 打开设置

可通过以下任一入口打开完整设置面板：

- Zotero“设置/首选项 → AI Hub → 打开 AI Hub 设置”。
- 右侧 Zotero AI Hub 区段中的“设置”。
- 文献右键菜单“Zotero AI Hub → AI Hub 设置”。
- 主工具栏中的设置入口。

### 4.2 厂商配置字段

每一个厂商配置行包含：

| 字段 | 作用 |
| --- | --- |
| 名称 | 用户可识别的配置名称。同一种厂商可以配置多个账号或端点。 |
| 类型 | 决定 API 协议和鉴权方式。 |
| Base URL | API 基础地址。OpenAI 兼容端点通常以 `/v1` 结尾。 |
| API Key | 厂商访问密钥；Ollama 本地服务可以留空。 |
| 默认模型 | 该厂商在没有明确指定模型时使用的模型。 |
| 自定义模型 ID | 用于输入候选列表中没有的新模型、别名或本地模型名。 |
| 优先级 | 使用“优先级”路由时，数字越小越先尝试。 |
| 启用 | 未启用的厂商不会参与正常调用与故障转移。 |
| 默认 | 未在任务中明确选择厂商时首先使用的厂商。 |

支持的厂商类型：OpenAI、Anthropic、Gemini、DeepSeek、通义千问、文心一言、Kimi、OpenRouter、Ollama，以及自定义 OpenAI 兼容端点。

### 4.3 推荐配置步骤

1. 在设置页厂商类型选择器中选择类型。
2. 点击“+ 添加厂商”。
3. 检查或填写名称、Base URL、API Key 和默认模型。
4. 勾选“启用”。
5. 选择该行的“默认”单选项。
6. 点击该行“测试”。
7. 测试成功后点击页面底部“保存设置”。
8. 看到“已保存 N 个厂商”才表示配置已写入本地。

“测试”会实际验证连接：OpenAI 兼容类和 Ollama 通过读取模型列表检查；Anthropic、Gemini、ERNIE 等使用相应的连接测试。

### 4.4 API Key 存储逻辑

API Key、旧版 ERNIE Secret Key 和 RAG Embedding Key 优先存入 Zotero/Firefox Login Manager。普通偏好配置中只保存不含密钥的厂商信息。旧版本遗留的明文密钥会在插件启动时迁移。

设置页的“显示/隐藏”只控制当前输入框是否明文显示，不会将密钥写入日志。

### 4.5 Ollama 本地模型

Ollama 的典型配置为：

- 类型：`ollama`
- Base URL：`http://localhost:11434`
- API Key：留空
- 模型：填写本机已安装的精确模型名，例如 `llama4` 或带标签的模型 ID

使用前需要启动 Ollama，并确保模型已经下载。例如在终端执行 `ollama pull <模型名>`。点击“刷新模型”时，插件调用 Ollama 的 `/api/tags` 读取本机实际模型。

### 4.6 文心一言凭证

当前千帆 v2 地址 `https://qianfan.bj.baidubce.com/v2` 使用单个 Bearer API Key。只有继续使用旧版百度 OAuth 端点时才需要同时填写 API Key（AK）与 Secret Key（SK）。

## 5. 模型列表与模型切换

插件同时使用两类模型列表：

- **内置候选列表**：用于首次配置和网络不可用时提供基础候选。
- **在线模型列表**：点击“刷新模型”后从厂商 API 获取，成功后优先采用在线结果。

### 5.1 设置页切换

在厂商行的“默认模型”下拉框选择模型；如果目标模型不在候选中，在“自定义模型 ID”输入框填入精确 ID。点击“保存设置”后，该模型成为该厂商默认模型。

### 5.2 右侧窗格切换

右侧窗格顶部有“厂商”和“模型”两个选择器：

- 切换厂商会载入该厂商自己的模型列表，并将其记为默认厂商。
- 切换模型会立即保存为该厂商默认模型，并在区段折叠摘要中显示“厂商 · 模型”。
- 点击“刷新模型”会从当前厂商 API 在线读取模型，不必进入设置页。
- 每次快速分析或问答都会把当前组合记到对应任务类型中。

模型名称由服务商控制。若出现“模型或接口路径不存在”，先点击“刷新模型”；如果仍未出现，请从服务商控制台复制模型 ID 到设置页的自定义模型输入框。

## 6. 右侧 Zotero AI Hub 内容窗格

Zotero AI Hub 使用 Zotero 原生的可折叠区段，与“信息”“摘要”“附件”等区段一致。点击区段标题右侧箭头可展开或折叠；折叠时会显示当前“厂商 · 模型”。

### 6.1 窗格组成

从上到下依次为：

1. 当前文献标题。
2. 厂商和模型选择器。
3. 配置状态、刷新模型、设置。
4. 快速分析六项操作。
5. 分析上下文编辑器。
6. 向当前文献提问。
7. 当前文献会话与历史输出。

### 6.2 分析上下文的三种来源

- **阅读器选文**：在 PDF/EPUB 中选中文本并打开 AI 助手，文本会传入当前文献的分析上下文。
- **载入文献**：点击“载入文献”，读取当前条目的标题、摘要、Zotero 笔记、PDF 批注和可用的 PDF/HTML/文本附件全文。
- **手工输入**：直接粘贴或编辑文本。

“使用最近选文”只允许恢复当前文献的最近选文。若选文来自另一篇文献，插件会阻止载入，避免跨文献误用上下文。

“清空”只清除上下文输入框，不会删除文献、批注或已经生成的会话。

### 6.3 快速分析

使用前应先选中文本、载入文献或手工输入上下文。

| 按钮 | 实际任务逻辑 |
| --- | --- |
| 摘要 | 使用摘要提示词生成结构化摘要。 |
| 解释 | 以保持学术准确为前提解释内容及关键概念关系。 |
| 批判分析 | 分析论点、证据、隐含假设、方法局限和可能反例。 |
| 智能批注 | 生成简洁的学术评论；来自已有 PDF 批注时可追加到该批注评论。 |
| 译为中文 | 保持学术语气和格式，将上下文翻译为中文。 |
| 关键词 | 提取重要关键词并解释它们在当前文献中的含义。 |

### 6.4 文献问答

1. 在“向当前文献提问”输入问题。
2. 可点击“核心贡献”“方法评价”“局限与展望”填入预设问题。
3. 点击“发送”，或按 `Ctrl+Enter`；macOS 可使用 `Command+Enter`。
4. 生成或 RAG 检索过程中“发送”会变为“停止”。点击后会立即中断底层网络请求、恢复“发送”按钮并显示“已停止，可重新发送”；用户取消不会自动切换厂商。

问答不仅使用分析上下文，还会自动加入当前文献最近最多 6 条已完成会话，以形成连续讨论。为降低首字延迟，单条历史最多取 3,000 字符、历史合计最多 12,000 字符；分析上下文超过 32,000 字符时会截取前 32,000 字符并给出提示。若启用 RAG，还会把语义检索结果附加到上下文，并要求模型引用 `RAG-N` 来源编号。

### 6.5 输出卡片

每次操作生成一个输出卡片，显示：

- 任务标题。
- 完成、生成中、已停止或错误状态。
- 实际选择的厂商与模型。
- 流式生成的正文。
- “复制”“保存笔记”“重试”“删除”操作。

各操作含义：

- **复制**：复制该卡片正文到系统剪贴板。
- **保存笔记**：把结果创建为当前 Zotero 文献的子笔记。即使右侧窗格当前拿到的是 PDF 附件或批注，也会自动定位到所属文献。
- **展开全文/收起**：长回答默认放在独立滚动区中，卡片显示完整字符数；需要连续阅读或复制时可展开全文。
- **重试**：恢复该次任务的上下文、问题和任务类型，再次请求。
- **删除**：只删除这一条 AI 会话记录，不删除 Zotero 文献或已保存的笔记。
- **清空会话**：删除当前文献的全部 AI 会话记录；生成进行中时需要先停止。

会话按文献 ID 隔离并持久化到 Zotero Profile 中的 `aihub-sessions.json`。最多保留 250 篇文献、每篇 60 条结果；单条结果最多约 120,000 字符。为减少保存整篇版权文本的风险，重试上下文最多保留 12,000 字符。

## 7. 阅读器选中文本操作

在 PDF/EPUB 阅读器中选中文字后，可以使用两种入口：

### 7.1 选文浮层

选文浮层中会出现：

- AI 助手：打开右侧窗格并载入选文。
- 摘要：对选文生成摘要。
- 智能批注：对选文生成学术评论。
- 译为中文：翻译选文。
- 问答：打开右侧窗格，把选文作为上下文，等待自定义问题。

### 7.2 阅读器原生右键菜单

右键选择“Zotero AI Hub”子菜单，可使用“打开右侧 AI 助手”“AI 摘要（选中）”“AI 智能批注（选中）”“AI 译为中文（选中）”和“基于选中内容问答”。

如果目标是一个已经保存的 Zotero PDF 高亮批注，“AI 批注”会优先把 AI 内容追加到该批注的评论字段，保留页码和位置关系。临时选区没有稳定批注 ID 时，用户可从输出卡片保存为带选文内容的 Zotero 子笔记。

## 8. 文献库右键菜单和工具栏

选中文献条目后，右键“Zotero AI Hub”可使用：

| 功能 | 选择要求 | 输出逻辑 |
| --- | --- | --- |
| AI 摘要 | 至少 1 篇 | 摘要第一篇选中文献。 |
| AI 多篇摘要 | 至少 2 篇 | 分析多个条目，结果归入第一篇文献会话。 |
| AI 批注 | 至少 1 篇 | 对当前文献可读取内容生成批注。 |
| AI 问答 | 可先选 1 篇 | 打开独立问答窗口并填入精简上下文。 |
| 生成文献综述 | 至少 2 篇 | 综合贡献、方法、结论和争议，结果归入第一篇文献会话。 |
| AI 翻译 | 至少 1 篇 | 翻译第一篇文献的可读取上下文。 |
| AI 思维导图 | 至少 1 篇 | 先生成层级大纲，再在独立窗口渲染为树形图。 |
| 导出笔记 | 至少 1 篇 | 生成摘要并导出为临时目录中的 `.docx` 文件。 |
| 打开右侧 AI Hub | 当前条目 | 展开并定位原生右侧内容窗格。 |
| AI Hub 设置 | 无 | 打开完整设置面板。 |

主工具栏还提供工作区、摘要、问答、批注和设置快捷入口。阅读器左上角不再显示旧版蓝色“AI Hub”按钮。

## 9. 文献内容读取与来源逻辑

点击“载入文献”或执行整篇文献任务时，插件依次收集：

1. 文献标题与摘要字段。
2. 文献下的 Zotero 子笔记。
3. PDF 附件内的高亮文字与批注评论。
4. PDF、HTML 或纯文本附件的全文索引。

全文优先读取 Zotero 附件文本；失败时尝试 Zotero Fulltext API 和全文缓存。若索引中保留分页符，则按真实页码标记；否则只标注“全文片段 N”，不会编造页码。

发送给模型的片段带有类似下面的来源标记：

```text
[来源：附件标题；第 3 页；source=pdf:123:page:3]
原文片段……
```

普通整篇上下文默认最多约 50,000 字符，尽量在来源片段边界截断，并添加“上下文已截断”提示。

如果“载入文献”提示没有可读取内容，应检查：

- 条目是否有摘要。
- PDF 是否已下载到本地。
- Zotero 是否完成全文索引。
- PDF 是否为只有图像、没有 OCR 文本的扫描件。

## 10. 自动保存与手动保存

设置中的“自动创建 Zotero 笔记”默认为关闭：

- 关闭时，结果只进入当前文献的 AI 会话，需要时点击输出卡片的“保存笔记”。
- 开启时，文献库菜单产生的摘要、翻译、综述等结果会自动创建子笔记。
- 右侧内容窗格中的“AI 问答”无论该开关是否开启，完成后都会自动创建当前文献的子笔记，避免研究问答只留在临时会话中。
- 对临时选文执行“智能批注”时，为保留来源，插件可能直接创建带选文的子笔记。
- 对已有 PDF 批注执行“AI 批注”时，优先写入该批注评论，而不是另建笔记。

保存为 Zotero 笔记会把常见 Markdown 标题、列表和段落转换为 Zotero 笔记 HTML。

## 11. 路由与故障转移

### 11.1 默认厂商

如果任务没有明确指定厂商，先使用设置中标记为“默认”的厂商；若默认配置不可用，则选择第一个已启用厂商。

### 11.2 优先级策略

使用“优先级”时，故障转移候选按 `priority` 数字从小到大排列。

### 11.3 轮询选项的当前行为

当前 1.4.2 中“轮询”保持厂商在配置表中的顺序，但尚未维护跨请求的轮转游标。因此它目前更接近“按配置顺序尝试”，并非严格的逐请求轮流分配。需要精确的轮询负载均衡时，应视为待完善功能。

### 11.4 故障转移

开启“故障转移”后，网络、鉴权、限流、超时或服务端失败会尝试下一家已启用厂商。用户主动点击“停止”产生的取消错误不会触发转移。

常见错误含义：

| 提示 | 排查方向 |
| --- | --- |
| 缺少 API Key | 检查密钥、厂商是否启用以及是否点击保存。Ollama 除外。 |
| 401/403 | 密钥无效、权限不足或账号无所选模型权限。 |
| 404 | Base URL 或模型 ID 不存在。 |
| 429 | 调用频率或额度受限，稍后重试或更换厂商。 |
| 请求超时 | 检查网络、本地模型性能或厂商状态。 |
| 所有厂商均不可用 | 检查启用状态、默认厂商、连接测试和故障转移顺序。 |

## 12. RAG 语义检索

RAG 用于从已索引文献中寻找与问题最相关的片段，再把这些片段作为回答上下文。

### 12.1 配置

1. 在“库内语义检索（RAG）”中勾选“启用 RAG”。
2. 填写 OpenAI 兼容的 Embedding API 地址。
3. 填写 Embedding Key；Ollama 本地嵌入端点可留空。
4. 填写嵌入模型，例如 `text-embedding-3-small` 或本地实际模型 ID。
5. 设置 Top-K，表示每次最多召回多少片段。
6. 选择检索范围并保存设置。

Embedding 地址既可填写完整的 `/embeddings` 地址，也可填写其上一级基础地址；插件会自动补全 `/embeddings`。

### 12.2 建立索引

1. 先回到 Zotero 文献库选择要索引的条目。
2. 打开设置页。
3. 点击“索引当前文献库”。按钮实际索引的是文献库中当前选中的条目，而不是自动遍历整个库。
4. 等待状态显示本次片段数、总文献数和总片段数。

每个来源片段按约 1,800 字符切块，相邻块重叠约 200 字符。重复索引某篇文献会替换该文献的旧记录，同时保留其他文献记录。向量索引保存在 Zotero Profile 的 `aihub-vectors-v2.json`。

### 12.3 检索范围

- 当前文献：只检索右侧窗格对应的文献。
- 当前选择：检索 Zotero 文献库当前选中的条目。
- 整个索引库：检索所有已经建立索引的文献。

RAG 检索失败时，右侧问答会显示错误，但仍会继续使用当前分析上下文回答。

## 13. MCP 服务

插件可启动本地 Streamable HTTP/JSON-RPC MCP 服务，默认地址为：

```text
http://127.0.0.1:23121/mcp
```

### 13.1 设置项

- 启用 MCP：控制服务是否启动。
- 端口：默认 `23121`，冲突时可修改。
- 允许远程访问：关闭时只监听本机回环地址；除非处于可信网络且明确需要，否则不要开启。
- 允许写操作：控制外部客户端能否创建 Zotero 子笔记，默认关闭。
- 重启服务：保存新设置后重新启动监听服务。

修改端口、启用状态或远程访问后，插件也会监听设置变化并尝试重启服务。

### 13.2 MCP 工具

| 工具 | 作用 | 写权限 |
| --- | --- | --- |
| `search_library` | 按标题关键词搜索当前 Zotero 文献库，最多返回 20 条。 | 否 |
| `get_item_details` | 读取条目标题、摘要和类型。 | 否 |
| `get_annotations` | 读取某条文献的批注文本。 | 否 |
| `get_collections` | 列出用户文献库收藏夹。 | 否 |
| `ai_summarize` | 对指定文献生成 AI 摘要。 | 否 |
| `ai_chat` | 基于客户端提供的上下文提问。 | 否 |
| `ai_annotate` | 为文本生成学术批注。 | 否 |
| `ai_translate` | 翻译文本到指定语言。 | 否 |
| `ai_mindmap` | 将文本转换为思维导图大纲。 | 否 |
| `zotero_add_note` | 向指定父条目创建子笔记。 | 是，需显式开启 |

外部客户端必须在 Zotero 正在运行且 MCP 状态显示“运行中”时才能连接。

## 14. 提示词模板

设置页可编辑以下模板：

- `summary`：普通摘要。
- `summaryDeep`：深度阅读摘要。
- `annotation`：选文批注。
- `chat`：文献问答系统提示。
- `translate`：翻译。
- `review`：多篇文献综述。
- `mindmap`：思维导图大纲。

占位符：

- `{{text}}`：待处理文本。
- `{{context}}`：文献或 RAG 上下文。
- `{{target}}`：翻译目标语言。
- `{{question}}`：可供自定义模板使用的问题变量；当前问答实现还会把问题作为独立用户消息发送。

不要删除任务必需的占位符，否则模型可能收不到文献正文。留空模板时，插件回退到内置默认模板。

## 15. 功能设置说明

| 设置 | 当前实际作用 |
| --- | --- |
| temperature | 控制随机性，默认 0.7。部分新模型协议不接受 temperature，适配器会按需省略。 |
| max_tokens | 控制最大输出长度，默认 4096。不同厂商可能按 completion token 解释。 |
| 自动创建 Zotero 笔记 | 控制多数菜单任务完成后是否自动写入子笔记。 |
| 故障转移 | 控制主厂商失败后是否尝试其他厂商。 |
| 路由策略 | “优先级”已完整生效；“轮询”当前仅保持配置顺序，见 11.3。 |
| 输出语言 | 值会保存，但当前 1.4.2 尚未统一注入所有任务；实际输出主要由各提示词决定。 |
| 系统提示词 | 值会保存，但当前 1.4.2 尚未统一附加到所有 AI 请求；需要统一风格时请修改具体任务模板。 |

后两项在界面中可配置，但当前并未贯穿全部功能链路；本文据实标注，避免误以为已经全局生效。

## 16. 隐私与数据边界

- 使用云端厂商时，插件会把当前任务所需的上下文发送到所选厂商 API。可能包含摘要、全文片段、笔记或批注。
- 使用本地 Ollama 时，模型请求发往配置的本地 Base URL；若自行改为局域网地址，数据会发送到该地址。
- RAG Embedding API 会接收被索引的文献片段以生成向量。
- AI 会话和 RAG 向量索引保存在本地 Zotero Profile。
- API 密钥优先保存在 Zotero/Firefox Login Manager。
- MCP 默认只监听本机；开启远程访问或写操作会扩大数据与修改权限，应谨慎使用。
- 在保存或索引受版权保护的全文前，应遵守文献许可、机构政策和所用 AI 服务条款。

## 17. 常见问题

### 17.1 右侧只有区段标题，没有正文

确认插件版本为 1.4.2，完全重启 Zotero，然后点击“Zotero AI Hub”区段右侧箭头展开。若仍无正文，先切换到另一个条目再切回。

### 17.2 快速分析没有按钮

1.4.2 已将六个按钮放在分析上下文上方。若只看到“快速分析”标题，应确认实际加载版本不是旧版缓存，并重启 Zotero。

### 17.3 API Key 或 Base URL 无法输入

应在完整 AI Hub 设置窗口中输入，不是在折叠区段摘要处输入。设置窗口中的厂商表格支持直接编辑、显示/隐藏密钥、逐行测试和保存。

### 17.4 找不到删除按钮

每个厂商行右侧“操作”列有“删除厂商”；表格下方有“删除全部厂商”。两者都会确认，且不会删除 Zotero 文献。

### 17.5 模型列表过期或没有目标模型

先点击“刷新模型”。如果厂商不提供在线模型接口或账户无列举权限，在设置页填写自定义模型 ID并保存。

### 17.6 生成内容为空

检查：

1. 厂商状态是否为已配置。
2. 模型是否为账号可访问的精确 ID。
3. 分析上下文是否有内容。
4. 设置页“测试”是否通过。
5. 输出卡片或状态栏是否显示 401、404、429、超时等错误。

### 17.7 扫描版 PDF 无法载入全文

扫描 PDF 通常没有文本层。需要先使用 Zotero 或外部 OCR 工具生成可检索文本，再让 Zotero 完成全文索引。

### 17.8 为什么问答引用了旧回答

右侧问答会把当前文献最近最多 6 条已完成会话作为连续对话上下文。需要从干净状态开始时，点击“清空会话”。

### 17.9 MCP 无法连接

确认 Zotero 正在运行、MCP 已启用、端口没有被占用，并使用 `http://127.0.0.1:<端口>/mcp`。修改设置后点击“保存设置”和“重启服务”。

## 18. 推荐使用方案

### 精读单篇论文

1. 打开 PDF，在右侧展开 Zotero AI Hub。
2. 选中关键段落并点击“AI 助手”。
3. 依次使用“解释”“批判分析”“关键词”。
4. 对关键高亮使用“AI 批注”写回评论。
5. 点击“载入文献”，再使用“核心贡献”“方法评价”“局限与展望”。
6. 将有价值的输出保存为 Zotero 子笔记。

### 综述多篇文献

1. 在文献库选择至少两篇条目。
2. 先执行“AI 多篇摘要”检查各文献要点。
3. 再执行“生成文献综述”。
4. 如需跨文献追问，为所选文献建立 RAG 索引，并将检索范围设为“当前选择”或“整个索引库”。

### 低成本或隐私优先

1. 使用 Ollama 配置本地模型。
2. RAG 也配置为本地 Embedding 端点。
3. 保持 MCP“允许远程访问”和“允许写操作”关闭。
4. 在发送前检查分析上下文，只保留任务所需内容。

## 19. 本地文件与清理范围

插件使用的主要本地数据：

| 数据 | 位置/机制 | 删除影响 |
| --- | --- | --- |
| 厂商和功能设置 | Zotero 偏好设置 | 不影响文献本身。 |
| API/Embedding 密钥 | Zotero/Firefox Login Manager | 删除后相应服务无法调用。 |
| AI 会话 | Zotero Profile `/aihub-sessions.json` | 只影响右侧历史输出。 |
| RAG 索引 | Zotero Profile `/aihub-vectors-v2.json` | 只影响语义检索，需要时可重新索引。 |
| 已保存 Zotero 笔记 | Zotero 文献库 | 属于正式文献数据，需在 Zotero 中单独管理。 |
| 写回的 PDF 批注评论 | Zotero 批注数据 | 属于正式批注内容，需在批注中编辑或删除。 |

设置页“删除厂商”只删除厂商配置与对应凭证，不会删除 AI 会话、RAG 索引、Zotero 笔记、文献或附件。
